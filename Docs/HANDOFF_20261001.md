## Gotchas learned this session

- **Editor vs game view:** `SM_Landscape_Far_01a` covers the docks at z≈970 in the editor and blocks Visibility traces there, but not in play. Ignore it in editor traces, and trust rendered PIE captures (`HighResShot` in an `editor`-mode PIE script) over editor views.
- **Audit blind spot:** the reachability audit traces on Visibility, so collision that ignores Visibility (such as `InvisibleWall`) is invisible to it.
- **Collision from Python:** turn collision off with `set_collision_profile_name('NoCollision')`. `set_collision_enabled` alone is reset by the profile on reload.
- **Material graphs from Python:** `connect_material_expressions` fails silently, so assert its return. Input names differ from the UI (Power uses `Base`/`Exp`).
- **Crash:** `EditorActorSubsystem.duplicate_actor` crashed the commandlet. Spawn a new actor and copy the mesh and materials instead.
- **Rotators:** `unreal.Rotator` positional arguments are (roll, pitch, yaw). Always use keywords.
- **Nested streaming:** streaming levels declared inside a *sublevel* are ignored. Stream them from `LV_Carnival` itself (the Shipwreck wreck was missing for this reason).
- **Door axes differ:** for hospital `BP_Door_0x` the passage is the actor's forward axis; for mansion `BP_Door02` it is the right axis (`CARNIVAL_DOOR_AXIS=right` in `probe_door_02a2_beyond.py`).
- **Fake doors:** several vendor doors open onto solid frames or walls. Probe what is behind a door before treating it as a route, and seal it with `seal_vendor_doors.py` if nothing is there.
- **Foliage:** single instances can't be removed safely from Python. Use `UCarnivalRouteEditorLibrary::RemoveFoliageInBox`. Vendor levels can also hold *orphan* foliage components that no record owns; find them with `DescribeFoliageInBox`. NightSnow has one, possibly a full duplicate set of snow spruces (a performance item).
- **Hidden lighting levels:** `get_all_level_actors()` on `LV_Carnival` misses the hidden `Lv_Lighting*` levels. Load those maps directly to inspect them.
- **Input mapping contexts:** in UE 5.8 the mappings are in `default_key_mappings.mappings`; the top-level `mappings` is empty. The asset registry still lists removed references until a fresh session.
- **HUD screenshots:** `HighResShot` omits the UI. Use `shot showui` (it writes to `Saved/Screenshots/WindowsEditor`). The first `shot` of a session can grab the editor viewport, so take a warm-up shot.
- **Teleport placement:** when placing the character in a rotated sublevel, check that the point is on the floor; a point in an AABB corner drops it outside.
- **Derived data goes stale:** route anchors were built from queue markers nobody used, and the audit and PIE tests read anchors from the authoring JSON rather than the map. Check which component actually owns a marker before trusting it, and read live tagged actors in audits.
