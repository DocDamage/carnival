## Contents

Each FBX includes a simple stickman preview mesh (skeleton lines) plus humanoid animation.
Retarget the animation to your own character mesh in Unreal Engine; the stickman is for preview only.

## Folder Structure
  Animations/     FBX animation files (import into Content/)
  Documentation/  This README

## Unreal Engine Setup
1. Copy the Animations/ folder into your project's Content/ directory (e.g. Content/Motifect/YourPack/Animations/).
2. In Content Browser, select all FBX files → right-click → Reimport (or import fresh).
3. Import settings:
   - Skeleton: create new skeleton from first file, OR use your Mannequin skeleton
   - Import animations: enabled
4. Retarget clips to UE5 Mannequin (recommended):
   - Use IK Retargeter (UE5) or Animation Retargeting tools
   - Source: imported Motifect skeleton / animations
   - Target: your project Mannequin (or included demo character)
5. Use sequences in Animation Blueprints, Control Rig, or Level Sequences.

TIP: Import and configure one FBX first, then batch-import the rest using the same skeleton.

## Compatibility
- Unreal Engine 5.0+ recommended (UE 4.27+ may work with manual skeleton setup)
- Animations are humanoid-compatible; retargeting required for non-matching skeletons
- Works with any render feature set (animations are data-only)
